# Manual operador

## Alcance inicial

El operador trabaja solo con su cartera asignada: clientes, solicitudes, vencimientos, reportes de cobro, cortes semanales y cuenta corriente propia.

## Flujo esperado

1. Registrar solicitud o cobro.
2. Adjuntar evidencia cuando aplique.
3. Preparar corte semanal.
4. Enviar corte para revision.
5. Dar seguimiento a devoluciones, faltantes o regularizaciones.

El operador no puede confirmar su propio corte ni acceder a cartera ajena.
